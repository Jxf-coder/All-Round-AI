# All-Round-AI

面向 Windows 10、Windows 11 和 macOS 的全新 AI 工作台实现。本项目本地优先，未来按同一套应用代码验证 Linux 服务器部署。

## 开发边界

- 原项目基线完整保存在 reference/source，仅用于只读分析，并由根 .gitignore 排除。
- 新实现放在 portable/；禁止直接编辑或提交 reference/source 中的业务代码。
- GitHub 私有仓库只接收新实现、项目文档和测试。未经用户明确要求，不推送参考基线。
- 每个阶段先实现，再运行该阶段的自动化检查与平台验收；问题修复并复测通过后，才进入下一阶段。

## 当前阶段

阶段 1：参考源隔离与跨平台基础设施。当前提供可注入平台参数的数据/缓存目录解析、目录创建与写入探测、JSONL 结构化脱敏日志、shell-free 子进程启动与停止，以及只绑定回环地址的本地健康检查运行入口。健康检查仅用于运行时验证，不代表工作台界面已实现。

## 环境

- Node.js 22.13 或更高版本
- npm（本地开发）或 GitHub Actions 使用的 npm

运行当前基础测试：

    npm test

启动当前基础运行时：

    npm start

然后访问 `http://127.0.0.1:3141/health`。通过 `ALLROUND_AI_PORT` 可更改监听端口；服务只绑定本机回环地址，不对局域网或公网开放。当前入口只是基础健康检查服务，工作台界面与业务功能将在后续阶段实现。
